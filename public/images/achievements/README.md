Drop achievement photos here using these filenames, then open
src/components/Achievements.jsx and set the matching `photo` field
from `null` to the path (e.g. '/images/achievements/astranova.jpg').

- education.jpg       -> CGPA / education card
- astranova.jpg        -> MediRoute AI / Astranova2k26 prize card
- sign-language.jpg    -> Sign Language Recognition card
- cattle-breed.jpg     -> Cattle Breed Classifier card

Recommended: roughly 4:3 or 16:9, at least 600px wide — cards crop to
a fixed height (112px) with object-cover, so exact aspect ratio isn't
critical.
